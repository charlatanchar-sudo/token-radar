Token Launch Radar

Protocols that record no token yet, ranked by what a launch would be worth if their record stayed as it is.

The model

Protocols whose token already trades are never ranked here; they set the category multiples the pre-token board is carried at. The watchlist is the floor, not the ceiling: every watchlist protocol is on the board, and the radar adds the pre-token protocols below the floor that pass the same product tests.
